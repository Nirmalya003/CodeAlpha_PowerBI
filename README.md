## 📊 Projects

### 1. SME Financial Health Dashboard

**Folder:** `Task-1-Financial-Health`

This project presents an interactive Power BI dashboard for analyzing the financial health of a small and medium-sized enterprise (SME).

The dashboard focuses on important financial indicators including:

- Total Revenue
- Net Profit
- Profit Margin
- Net Cash Flow
- Total Assets
- Revenue and Profit performance

#### Key Features

- KPI cards
- Financial performance analysis
- Profitability analysis
- Cash-flow analysis
- Interactive Power BI visualizations
- Financial performance monitoring

#### Files

- `PowerBI_Task1_Financial_Health.pbix`
- `SME_Financial_Health_2_Year_Dataset.xlsx`

---

### 2. Human Resources Analytics Dashboard

**Folder:** `Task-2-HR-Analytics`

This project presents an interactive HR analytics dashboard designed to analyze employee characteristics, performance, satisfaction, turnover, training, salary, and recruitment information.

#### Key Features

- Total Employees
- Turnover Rate
- Average Salary
- Average Satisfaction
- Average Performance
- Employee distribution by department
- Employee turnover analysis
- Salary analysis
- Training analysis
- Recruitment analysis
- Employee satisfaction vs performance
- Interactive filters

#### Dashboard Filters

The dashboard includes filters for:

- Department
- Gender
- Job Level
- Turnover

#### Files

- Power BI Task 2 `.pbix` file
- HR analytics Excel dataset

> **Note:** The HR dataset used for this project was created as a sample dataset for the internship project.
